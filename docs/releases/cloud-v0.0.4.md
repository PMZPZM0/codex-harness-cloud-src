# cloud-v0.0.4 发版说明（Codex Harness Assistant）

本版主题：**主界面变成正经的应用窗口** —— 配对那一下之后，不再把浏览器当主界面。

> ⛔ 0.0.1 装完即崩、0.0.2 装完不出现界面、0.0.3 主界面是浏览器标签页 —— 请直接用本版。

## 一、本版变化（0.0.3 → 0.0.4）

- **主界面是应用窗口**：启动后打开一个真正的桌面窗口（任务栏有图标、可以最小化/最大化/关闭），
  不再是浏览器标签页。窗口里就是完整的助手界面。
- **首次配对也在窗口里完成**：未配对时窗口直接弹出配对框，输入 8 位配对码即连——
  **全程不需要打开浏览器**。浏览器访问 `http://127.0.0.1:8917` 仍然可用（手机、其他电脑都走这条），
  只是不再是主形态。
- **关闭窗口 = 最小化到托盘**（不是退出）：助手要继续给浏览器/手机端提供服务；
  真要退出请右键托盘图标 →「退出」。
- **托盘「打开助手界面」**：把窗口带回前台（0.0.3 起就有，本版行为随窗口形态一起更新）。

## 二、0.0.3 已修（本版同样包含）

- 装完启动后不出现任何界面（无窗口 + 不弹浏览器 + 托盘没入口）——已改为启动即开窗口；
- 未配对不弹配对框（此前要等第一次请求失败才弹，新手看到的是空白界面）——已改为进界面即弹；
- 覆盖安装卡死（安装程序先强杀托盘常驻进程）；
- 安装后启动崩溃（打包清单补齐运行期 `.mjs`）；
- 更新线独立：助手只认 `cloud-v*` 版本 + `CodexHarnessAssistant-*` 安装包，
  不会把桌面版 Codex Harness 的更新当自己的；
- 自动更新：后台静默检查（启动 30 秒后 / 每 6 小时）、速度与剩余时间、取消 / 断点续传 / 稍后安装 / 跳过版本。

## 三、安装

**Windows**：下载 `CodexHarnessAssistant-0.0.4-win-x64-setup.exe` → 双击安装 → 完成后自动启动并打开窗口。

**macOS**：下载对应芯片的 zip（Apple 芯片 `arm64-mac.zip`，Intel `x64-mac.zip`）→ 解压 → 拖进「应用程序」；
首次打开若提示无法验证开发者：终端输入 `xattr -cr `（末尾空格）后把 app 拖进终端补全路径，回车再双击。

## 四、首次使用

1. 启动后窗口自动打开（未配对时窗口内直接弹配对框）；
2. 到 https://ppz123.asia 注册/登录 → 输入本机签发的 8 位配对码；
3. 在「设置 → 模型」里填入你自己的模型账号；
4. 开始使用。此后开机自启，任何浏览器打开 https://ppz123.asia 登录即连。

## 五、已知问题

- 配对码目前只能由本机命令行签发：`"Codex Harness Assistant.exe" --add-user 你的名字`
  （签发时打印一次 8 位码）。界面内一键签发正在做；
- 工具链（Node/Python/rg）按需下载的服务端分发目录仍在准备中：MCP/脚本类能力可能降级
  （引擎与对话不受影响）。
