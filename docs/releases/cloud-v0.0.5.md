# cloud-v0.0.5 发版说明（Codex Harness Assistant）

本版主题：**配对不用命令行** —— 界面里点一下就能签发配对码，顺便把窗口标题改对。

> ⛔ 旧版请全部弃用：0.0.1 装完即崩、0.0.2 装完不出现界面、0.0.3 主界面是浏览器、0.0.4 配对要命令行。

## 一、本版变化（0.0.4 → 0.0.5）

- **配对框里一键签发配对码**：第一次用这台电脑，直接点「在本机签发一个配对码」——
  生成的 8 位码会自动填进输入框，再点「连接」即可。**完全不需要命令行**
  （此前唯一入口是 `--add-user`，普通用户根本拿不到码）。
  - 签发有节流：60 秒内最多 3 次，防止被脚本刷；
  - 同一台电脑重复点不会堆出一堆用户（同名复用，旧码作废）。
- **窗口标题修正**：助手窗口此前会顶着桌面版的名字（"Codex Harness Desktop"），
  现在固定显示 **Codex Harness Assistant**（页面标题不再覆盖窗口标题）。

## 二、0.0.4 已带（本版同样包含）

- **主界面是应用窗口**（任务栏有图标、可最小化/关闭），不再是浏览器标签页；
- **关闭窗口 = 最小化到托盘**（服务继续给浏览器/手机用），退出走托盘右键 →「退出」；
- 首次配对也在窗口里完成（**不必打开浏览器**；浏览器访问 `http://127.0.0.1:8917` 仍然可用）；
- 未配对时进界面立即弹配对框（不用等第一次请求失败）；
- 托盘右键 →「打开助手界面」把窗口带回前台；
- 覆盖安装卡死修复 / 安装后启动崩溃修复 / 更新线独立（只认 `cloud-v*` + `CodexHarnessAssistant-*`，
  不会被桌面版 Codex Harness 的更新干扰）/ 自动更新（后台静默检查、进度与剩余时间、取消、断点续传、稍后安装、跳过版本）。

## 三、安装

**Windows**：下载 `CodexHarnessAssistant-0.0.5-win-x64-setup.exe` → 双击安装 → 完成后自动启动并打开窗口。

**macOS**：下载对应芯片的 zip（Apple 芯片 `arm64-mac.zip`，Intel `x64-mac.zip`）→ 解压 → 拖进「应用程序」；
首次打开若提示无法验证开发者：终端输入 `xattr -cr `（末尾空格）后把 app 拖进终端补全路径，回车再双击。

## 四、首次使用（本版开始只需两步）

1. 启动后窗口自动打开 → 弹出配对框 → 点「**在本机签发一个配对码**」→ 点「连接」；
2. 在「设置 → 模型」里填入你自己的模型账号，开始使用。

以后开机自启；任何浏览器打开 https://ppz123.asia 登录即连（手机、其他电脑同一台助手）。
