# cloud-v0.0.7 发版说明

本版主题：**云端账号体系落地 —— 登录闸、三中心门户、会话上传/同步与配额**

> 版本号说明：云助手走自己的版本线（`0.0.x`，钉在 `electron-builder.assistant.yml` 的 extraMetadata），
> 与桌面版 `0.0.38` 的版本线互不污染；tag 形如 `cloud-v0.0.7`。

## 一、改了什么（按用户感知排序）

1. **登录优先**：内置应用改为「先验证登录，再加载界面」—— 未配对时应用一行代码都不加载，
   只显示配对页（配对码 + 复制 + 刷新 + 换账号 + 取消并退出）。彻底删掉了此前"配对卡"方案。
2. **配对健壮性**：机器身份（installation_id）成为查询主键，配对码只做握手。
   → 手填旧码、换浏览器、重装助手都能接上，不再出现"回调页等 80 秒报授权未完成"。
3. **三个中心（网站）**：`/cloud/account.html` → 用户中心 / 配对中心 / 云端管理，
   桌面左导航、移动端顶部标签；非管理员看不到「用户管理」入口。
4. **会话上传与同步（P0+P1，闭环）**：
   - 上传：本机按行增量推（启动后一次 + 每 5 分钟 + 手动）；8.5MB 会话自动分片，幂等无重复
   - 下载：云端 → 本机一键恢复，按会话自身时间戳落回本地会话列表；重复下载自动跳过
5. **配额规则**：每账号最多 **3 台机器**（同机重配不占名额）、**1 GB 存储**；
   超限给明确提示并阻止，界面有 X/3 与用量条（80%/95% 变色）。
6. **云端数据管理**：会话列表（名称/项目/所属机器码/上传时间/大小/行数）+ 单条删除 + 按项目批量删除 +
   解除机器配对；删除云端不影响本机文件。
7. **界面与品牌**：产品名统一 Codex Assistant，数据目录 `AppData/Roaming/Codex Assistant`
   与 `~/Codex Assistant`，界面资产整份从服务器加载（客户端只是壳）。

## 二、平台适配审计结论

本版为云助手的首个功能版，改动集中在本机运行时（Electron 主进程 / 云端网页）。
Windows 侧已实测：配对、上传、下载、配额拦截、会话列表。
macOS 侧沿用桌面版既有适配（`path.delimiter`、`fileURLToPath` 等既有约定），本版**未新增**
平台敏感代码路径；mac 构建由 CI 同步产出。

## 三、macOS 首次打开自救

1. 在「下载」里解压得到 `Codex Assistant.app`；2. 拖进「应用程序」；
3. 首次打开若被 Gatekeeper 拦：右键 → 打开 → 再点「打开」；
4. 仍被拦时在「终端」执行：`sudo xattr -dr com.apple.quarantine "/Applications/Codex Assistant.app"`
   （把图标拖进终端可自动填路径，不必手打）；5. 错误 640 表示文件仍在 quarantine，重复第 4 步即可。

## 四、已知问题

- 会话同步为**单向上传 + 手动下载**；自动下载、冲突解决 UI、项目/记忆/技能同步按设计文档
  （`cloud/docs/CLOUD-SYNC-DESIGN.md`）的 P2–P4 推进。
- 云端会话标题目前取首条用户消息；取不到时回落为会话 id 前 8 位。
