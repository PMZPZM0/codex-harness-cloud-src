# Codex Harness Assistant 0.0.51 发版说明

本版为**维护版**：与桌面版 v0.0.53 同批对齐，内容为媒体预览体验与发版校验修正，无破坏性变更。

## 一、修了什么

### 1. 媒体预览倍速改为应用内下拉
视频与音频工具条上的倍速选择原来是浏览器原生 `<select>`，弹层不跟主题（暗色下白底）。改用 `AppSelect`，与其它下拉一致。

### 2. OpenFilm 卡片补回「卸载只做引导」
重构时这句用户可见文案被移入注释，界面上丢失。已补回：卸载只告诉你到系统里怎么删，不代删安装目录。

### 3. 发版校验判据修正
- 播报条宽度判据锚定基础规则（避开遮罩期隐藏规则）；
- favorites 拆域后产物路径改为多候选探测；
- `applyWindowChrome` 判据接受可选第二参；
- bag-types 与实现一致（`install/uninstall` 返回 `boolean`）。

## 二、升级方式

应用内「检查更新」→ 下载完整包覆盖安装。本版未引入配置格式变更，无需迁移。

## 三、已知问题

- 影视播放仅支持公网片源；
- 云助手沿用桌面版品牌与图标（非独立品牌）。
