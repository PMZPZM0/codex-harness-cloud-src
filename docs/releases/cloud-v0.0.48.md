# cloud-v0.0.48 发版说明

本版主题：**与桌面版 v0.0.51 同批同步 —— 文件卡片三级找回、CLI 智能体板块，mac 修掉三处硬伤。**

> 版本号说明：本仓的包版本走 `cloud-v` 发布线（`electron-builder.assistant.yml` 的
> `extraMetadata.version`），与桌面版 `package.json` 的版本线互不污染。

## 一、主要更新

- **文件在哪都能打开**：卡片路径是死链时按「命令自己的 cd → 会话台账 → 扫盘找同名文件」三级找回；
  预览与编辑不再弹授权框。
- **命令卡看得懂了**：图标按动作区分、文件名可点联动预览、改了文件后面标 `+N −M`。
- **新增 CLI 智能体板块**：本机 CLI 检测 / 安装命令 / `@` 点名派活。
- **`@` 列表跟着调度开关走**：未开通专家团调度时置灰不可选，开通即恢复。
- **mac 修好三处硬伤**：旧引擎残留认不出（`/proc` 在 mac 不存在）、本机 CLI 一律显示未检测
  （写死 `where`）、派活给 CLI 成员必失败（写死 `cmd /c`）。
- **扫盘找回**：mac 上不再把 `/` 当「盘根」扫整个文件系统，并按绝对路径跳过 `~/Library`。

其余为与桌面版同步的界面与技能市场修复。

## 二、mac 首次打开自救（带路径）

未做公证，首次打开会被 Gatekeeper 拦。打开「终端」，**把图标拖进终端窗口**（自动补全路径），
在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/Codex Assistant.app"
```

只需一次，升级后不用重复。若提示 **错误 640**，是同一个 quarantine 属性，执行上面的命令后重开即可。

## 三、已知问题

- mac 未签名未公证，只有 `xattr -cr` 一条路；分发包不是 universal 二进制（资产名带 `x64` / `arm64`）。
- 云端界面（`src/**`）改动需部署到服务器才生效。本版 `src/**` 只删了技能汇总条的**死规则**
  （对应组件早已移除，类名全仓 0 引用），界面无可见变化，因此本次未重新部署云端界面。
