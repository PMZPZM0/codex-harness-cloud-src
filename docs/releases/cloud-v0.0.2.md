# cloud-v0.0.2 发版说明（Codex Harness Assistant）

本版主题：**修好 v0.0.1 的启动崩溃 + 自动更新 + 三端齐全**。

> ⛔ **v0.0.1 请勿使用**：该版 Windows / macOS 包存在「安装后启动即崩溃」
> （`Cannot find module '../src/lib/video-providers.mjs'`）——打包文件清单漏了运行期 `require` 的
> `.mjs`，本版已修复。**已装 v0.0.1 的请直接下载安装本版**（覆盖安装即可）。

## 一、修复

- **安装后启动崩溃**：打包清单补 `src/lib/*.mjs` 与托盘图标资源，装完能正常启动；
- **覆盖安装卡死**：安装程序加 preInit 强杀钩子——托盘常驻进程不退出会导致新版装不上（必须手动杀进程才能装）；
- **mac 托盘图标**：改用 PNG（electron-builder 的 mac 目标不认 .ico，v0.0.1 上托盘图标缺失）；
- **mac Intel 包补齐**：v0.0.1 的 x64 构建卡在 CI 队列（Intel runner 拥堵，排队十余小时未启动），本版换成较空闲的 Intel runner，**首次做到 Windows + mac Apple 芯片 + mac Intel 三端同时出包**。

## 二、新增：自动更新（助手独立更新线）

- 更新线独立：助手只认 `cloud-v*` 标签与 `CodexHarnessAssistant-*` 资产，不会误拉桌面版的更新；
- 后台静默检查：启动 30 秒后首查，之后每 6 小时一次；断网自动跳过、失败按 5 分钟 → 15 分钟 → 1 小时 → 6 小时退避；
- 可见进度：已下载 / 总量 / 实时速度 / 剩余时间（样本不足时留空，不给假数字）；
- 可控：下载中可取消、断点续传、可选「稍后安装」、可跳过某个版本。

## 三、这是什么（首次使用请看）

Codex Harness 的**应用版客户端**：本地助手跑引擎与真界面，浏览器或本应用都能用；登录与界面更新走 ppz123.asia，**会话与数据全部在你自己的电脑上**。

- 双击安装即用；引擎内置（Codex 官方二进制）
- 连接云端服务器：注册/登录 → 输配对码 → 多设备管理
- 事件实时推送（SSE），非轮询
- 工具链（Node/Python/rg 等）按需下载（国内镜像），安装包保持精简

## 四、安装

**Windows**：下载 `CodexHarnessAssistant-0.0.2-win-x64-setup.exe` → 双击安装 → 完成后自动启动。

**macOS**：
1. 下载对应芯片的 zip（Apple 芯片选 `arm64-mac.zip`，Intel 选 `x64-mac.zip`）；
2. 在「下载」里解压，把 **Codex Harness Assistant.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（注意末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。

## 五、首次使用

1. 启动后自动打开界面（或浏览器访问 `http://127.0.0.1:8917`）；
2. 首次使用会要求配对：到 https://ppz123.asia 注册/登录 → 输入本机签发的 8 位配对码（设置或控制台可见）；
3. 在「设置 → 模型」里填入你自己的模型账号；
4. 开始使用。此后每次开机启动助手，任何浏览器打开 https://ppz123.asia 登录即连。
