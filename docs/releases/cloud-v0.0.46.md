# cloud-v0.0.46

本版主题：**思考过程折叠演进 + 云助手网关代理令牌回退，与桌面版 v0.0.46 同批同步。**

## 改了什么

本版为 v0.0.45 之后 7 个提交的打包发布（与桌面版同批功能在云助手线的落地）：

### 1. 思考过程折叠
- 回合结束后思考内容**折叠进回合过程组**，不再常驻刷屏。

### 2. 思考长条（strip 展示模式）
- 折叠态下保留一条过程样式的横条 + 最新一行要点，**自动滚动**跟随直播；与自适应浮层两种模式并存。

### 3. 直播过程尾部收敛
- 各类过程项的直播尾部统一设上限：长时间运行的工具不再把界面撑得无限长。

### 4. 网关代理令牌回退
- 本机没有独立云账号凭据时，回退读限时福利令牌——服务器按身份完整性拒绝不完整请求，**不会误归属**（云端记忆与身份链路配套）。

## mac 适配审计

本版 7 个提交涉及平台的改动：无新增 darwin/macos 敏感代码；`responses-bridge` 的令牌读取在本仓两个模块（`cloud-token` 不存在 ⇒ `features/limited-benefit-ipc`）都真实存在，require 可解析（主仓同段只保留 cloud-token 一支，属各仓各自正确形态）。结论：**无真缺口**。

```bash
xattr -cr "/Applications/Codex Assistant.app"
```
