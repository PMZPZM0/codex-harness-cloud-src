# Codex Harness Assistant 0.0.8

## 修复
- **删除模型不生效 / API Key 反复被清**：供应商草稿被启动加载逻辑反复覆盖的真凶（useEffect 依赖写法），彻底修复
- **首次进入应用列表全空、二次进入才正常**：云助手 userData 被钉在旧锚点目录的根因修复
- **启动竞态**：供应商/会话列表读到空不再卡住（指数退避重试）
- **每个回合弹「Project-local config … disabled until trusted」警告**：启动自愈信任表，不再刷屏
- 测试连接的 429（限流）/ 403（未勾选）不再误报为「连接失败」，提示改为可照做的指引
- 模型配置界面显示真实上下文额度/输出上限/多模态支持（不再硬编码默认值）
- 勾选写回失败时回滚并明确提示（不再静默丢勾选）

## 新增
- 「限时福利」面板新增「勾选后怎么用」教程按钮（两步：刷新模型列表 → 保存重启）
- 勾选后自动同步模型配置并轻提示

## 提醒
- 未勾选的模型不会出现在模型配置界面的下拉框里
- `deepseek-v4.1-flash` 为共享免费池，高峰期可能触发上游限流（429），等待 1-2 分钟重试即可
