# v0.0.54 发版说明

本版主题：**工作伙伴（群聊）全面对齐主对话 + CLI 智能体自动跟随你的模型配置（云侧同源）。**

> **版本号说明（必读）**：上一版 **cloud-v0.0.53 未产出可下载安装包（上传步骤失败），请用本版**。同时 GitHub 的 `macos-14` runner 已于 **2026-11-02 退役**，本仓 mac 矩阵改为 `macos-15`。本版需要**云端界面重新部署**才会生效。

## 一、修了什么（按用户感知排序）

### 1. 工作伙伴（群聊）与主对话对齐
- 回合视图：逐条实时上屏、过程大折叠、轮末汇总卡；补齐用量页脚 / 推理浮窗 / 网页来源条；
- 输入框 @ 行内 chip、引用居中弹窗、伙伴资料卡、@ 候选面板、群内搜索；
- 成员头像可自定义（只作用于本群）。

### 2. 群伙伴直接用本机 CLI 回话
- CLI 成员改本地进程直接回复；修掉 Qwen 405、Kimi 连不上旧中转、Claude 参数族错误、stdin 未关闭丢正文；
- 失败时给「下一步怎么做」，不再显示原始 JSON。

### 3. CLI 智能体自动跟随模型配置
- 装好即配、切供应商自动更新；
- 模型配置页「同步给 CLI」弹窗：每个 CLI 一个定制按键；Claude / iFlow 写自己的配置文件（提示密钥明文、二次确认），Codex / Kimi 不含密钥，Qwen 等自动注入，其余如实标注需自己登录；
- 写入修正：内容一致算成功、坏 JSON 不覆盖、首次改动留备份。

### 4. 更新机制
- 组件更新加官方源兜底（滞后镜像不再挡住官方源），19 个运行时依赖升到最新。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.52 HEAD`：命中 115 条，判读后本版新增逻辑无真缺口（平台门控 / 夹具 / 文案）；CLI 相关两处为误报（win32 三元门控、正则 `\s` 被当路径转义）。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里双击解压；2. 拖进「应用程序」；3. 把图标拖进「终端」让它自动填路径；4. 路径前加 `xattr -dr com.apple.quarantine ` 回车；5. 错误 640 时用系统「归档实用工具」重新解压。
