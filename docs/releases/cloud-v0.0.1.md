# cloud-v0.0.1 发版说明（Codex Harness Assistant）

本版主题：**云助手首个版本** —— 桌面双击即用的应用版客户端，连接 ppz123.asia 云端。

## 一、这是什么

Codex Harness 的**应用版客户端**（与浏览器网页版同源同形）：本地助手跑引擎与真界面，浏览器或本应用都能用；登录与界面更新走 ppz123.asia，**会话与数据全部在你自己的电脑上**。

- 双击安装即用；引擎内置（Codex 官方二进制）
- 支持连接云端服务器：注册/登录 → 输配对码 → 多设备管理
- 事件实时推送（SSE），非轮询
- 工具链（Node/Python/rg 等）按需下载（国内镜像），安装包保持精简

## 二、Windows / macOS 安装

**Windows**：下载 `CodexHarnessAssistant-0.0.1-win-x64-setup.exe` → 双击安装 → 完成后自动启动。

**macOS**：
1. 下载对应芯片的 zip（Apple 芯片选 `arm64-mac.zip`，Intel 选 `x64-mac.zip`）；
2. 在「下载」里解压，把 **Codex Harness Assistant.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（注意末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。

## 三、首次使用

1. 启动后自动打开界面（或浏览器访问 `http://127.0.0.1:8917`）；
2. 首次使用会要求配对：到 https://ppz123.asia 注册/登录 → 输入本机签发的 8 位配对码（设置或控制台可见）；
3. 在「设置 → 模型」里填入你自己的模型账号；
4. 开始使用。此后每次开机启动助手，任何浏览器打开 https://ppz123.asia 登录即连。
