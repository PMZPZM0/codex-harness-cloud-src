# 模型供应商启用互斥与云端模型目录刷新

# 模型供应商启用互斥 + 云端模型目录刷新

## 起因
用户实测：启用新供应商时旧供应商没有自动停用；云端模型列表不自动刷新，手动刷新报 /models 错误，手动加模型又出现。

## 结论
- UI 去掉阻止启用新供应商的 disabled；provider-activated 后刷新整张供应商列表；主进程 withExclusiveEnabled 继续兜底。
- 云端供应商列表刷新改走 cloud-models:sync（不探 /models），云端行模型自动同步进编辑草稿。
- 云助手保留 cloudLocked（云端模型模式）语义，只解除「另一个供应商生效时禁止启用」这一层。

## 验证 / 影响
- tsc 通过；守卫【15】通过；云助手 UI 需部署。
- 预检仍余若干与本改动无关的基线红（部署哈希 / 内置 python / 发布说明等）。
